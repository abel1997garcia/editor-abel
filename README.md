# Sistema de edición de Abel

Todo el sistema de trabajo de Abel García, sin vídeos ni contraseñas:
- el editor de vídeos (horizontales y reels F1-F4), con sus reglas (gancho, colleja, una idea, verificador de audio, estilo de voz y música);
- la FÁBRICA DE CONTENIDO, la música y las imágenes;
- las skills y la memoria de Claude;
- los flujos de n8n (YouTube e Instagram) y la tarea programada.

Para instalarlo en otro ordenador, sigue [INSTALAR.md](INSTALAR.md). Para actualizar la copia: `python actualizar_copia.py --subir` (y `--usb` para el zip).
