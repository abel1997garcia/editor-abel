# Biblioteca de efectos de sonido de Abel

Los mismos efectos del horizontal aprobado («regula tu dopamina v2»), sintetizados y sin derechos (`CREDITOS.md`).
`sonidos.json` = archivo, duración, punto de anclaje (`ancla`), ganancia base (`gain_db`) y descripción de cada uno.
Su voz nunca se toca: los efectos van por debajo, con el volumen de la columna «vol» (como en el horizontal).
Nunca dos efectos a menos de 0,3 s.

| Momento | Efecto | vol |
|---|---|---|
| Entra un texto normal / subtítulo destacado | `tick-suave` | .22 |
| Entra un título grande (≥ 100 px) o el título del reel | `golpe-corto` | .30 |
| Entra un emoji o una imagen pequeña | `pop` | .30 |
| Marca ✓ / lista que se completa | `tick` | .30–.35 |
| Marca ✗ / algo que se descarta o se tacha | `descarte` | .35 |
| Cambio de plano o de imagen (F2), tablero ↔ él (F3) | `aire` o `barrido` | .25–.30 |
| Cifra o contador que impacta, golpe de efecto | `golpe` / `impacto` | .30–.40 |
| Algo que sube o crece (barra, medidor) | `subida` | .30 |
| Notificación, móvil, redes | `notificacion` | .30 |
| Momento de calma, revelación, energía que se expande | `swell` / `brillo` | .25–.35 |
| Corte con tijeras, algo que se corta | `corte` | .45 |
| Error, fallo, batería vacía | `fallo` | .25 |
| Remate final de una idea | `nota` / `nota-doble` | .35 |
